# Contributing to Ogun

Thanks for trying Ogun! It is in **public beta**, and the most useful thing you can do is use it and tell me what happens.

## How to help

- **Report bugs** and **failed builds** with the issue templates. The build log and `./run_ogun.sh --hardware-info` output make problems much easier to fix.
- **Send feedback**: what you used Ogun for, what confused you, and what's missing.

## Pull requests

I'm **not accepting pull requests** at the moment. Ogun is source-available under the [Functional Source License](LICENSE) and may become a paid product, so I need to own all of its code. If you've found a fix, please describe it in an issue instead and I'll implement it, with credit in the changelog.
